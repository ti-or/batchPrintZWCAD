# LA批量打印插件 v1.16.0 发布说明

本版本为功能版本，适用于 ZWCAD、AutoCAD 2015–2024 与 AutoCAD 2025–2027。

## 新增：纸质打印（直接送系统打印机/绘图仪）

此前插件只能输出 PDF、PNG、JPG、DWF 等电子档，或按图框拆成 DWG；本版本新增「纸质」输出格式，把每个图框直接送到 Windows 打印机/绘图仪。

### 使用方式

1. 打开「批量打印」或「通用型批量打印」窗口，输出格式选择「纸质」。
2. 窗口出现「打印机 / 份数 / 纸张不匹配时改用最接近的纸张」一行；保存路径与合并 PDF 控件自动隐藏。
3. 选择打印机、设置份数（1–99），点击「开始打印」。
4. 插件按清单顺序逐张出图，完成后提示已送打印机多少张。

### 纸张匹配

- 按打印机驱动上报的纸型物理尺寸匹配图框图幅，容差 3 mm。
- 缺纸时默认停止并列出打印机可用纸张，不会把 A1 悄悄打到 A4。
- 勾选「纸张不匹配时改用最接近的纸张」后，按长宽比与尺寸选择最接近的纸张，避免把 A3 放大铺满 A0 或整卷纸。

### 与电子输出的差异

- 不生成任何输出文件，因此不提供「保存路径」「合并 PDF」「周边留白」。
- 纸张完全由打印机驱动决定；加长纸等幅面需先在 Windows 打印机属性中添加。
- 份数交给打印引擎/驱动处理，个别驱动会忽略份数。
- CTB 打印样式、打印透明度、按对象线宽、不打印外边框等设置继续生效。

### 界面与记忆

- 批量打印窗口记住上次的输出格式、打印机、份数和改纸开关。
- 纸质模式下清单「输出」列显示「打印到 &lt;打印机&gt; × N 份」。
- 进度窗、日志与完成提示改用「打印机 + 份数」描述。
- 单张打印（`ZBP_SINGLE_PLOT`）仍输出 PDF；需要纸质输出请用批量打印窗口，只勾选一张即可。

## 实现要点

- `PlotJob` 新增 `PrintToDevice`、`Copies`、`AllowClosestPaper`；纸质作业 `OutputPath` 不参与出图。
- `PlotEngine.BeginDocument` 按 `plotToFile=false` 送设备，份数通过 `copies` 参数交给引擎。
- 纸质作业跳过 `PrepareOutputFile` / `ValidatePlotOutput`，也不向 PMP 注册任意纸张。
- 系统打印机不做「空白图驱动预热」，避免预热时真的吐一张白纸。
- 文字转图形仅对插件自有 `LA_pdf`/`LA_dwf` 生效，纸质打印不再因为该选项被拒绝。
- AutoCAD 复用 `GetMediaCatalog` 的毫米尺寸；ZWCAD 逐个介质读 `PlotPaperSize` 并对英寸驱动做换算兜底。

## 安装说明

与以往版本相同：按平台解压对应 ZIP，按说明 NETLOAD 或使用自动加载；升级时请先关闭已加载旧 DLL 的 CAD 进程后再替换文件。
